# Day 1 — Git & GitHub Basics

Set up dev-journal repo. Learned:
- git clone: pulls a copy of a GitHub repo to your machine
- three zones: working directory -> staging (git add) -> committed (git commit)
- git push/pull: syncs local commits with GitHub
- git status: shows what's staged/unstaged, use it constantly
- git log / git show: view commit history
- git checkout -- <file>: discard uncommitted changes to a file

Practiced in a throwaway playground repo (not dev-journal) to avoid messing up real history.
